# B2B SaaS Cold Outreach Research

This repository is a structured workspace to collect, organize, and synthesize insights for **B2B SaaS cold outreach**.

## Project Goals

- Build a high-quality source library for outbound strategy.
- Extract actionable outreach tactics from trusted creators and case studies.
- Turn insights into reusable messaging frameworks (email + LinkedIn).
- Support repeatable experiments to improve reply and meeting-booked rates.

## Repository Structure

```text
research/
├── linkedin-posts/         # Saved LinkedIn post notes
├── youtube-transcripts/    # Video transcript summaries and insights
├── other/                  # Blogs, newsletters, playbooks, case studies
└── sources.md              # Master list of references and action items
```

## Research Workflow

1. Add each new reference to `research/sources.md`.
2. Save raw notes in the appropriate folder:
   - LinkedIn -> `research/linkedin-posts/`
   - YouTube -> `research/youtube-transcripts/`
   - Other sources -> `research/other/`
3. For every source, capture:
   - ICP or segment discussed
   - Outreach angle and message structure
   - CTA pattern
   - Any reported metrics or outcomes
4. Promote high-confidence insights into testable outreach hypotheses.

## Priority Research Themes

- ICP definition and segmentation for B2B SaaS.
- First-touch cold email and LinkedIn DM structure.
- Follow-up sequencing (timing, channel mix, content variation).
- Personalization at scale without losing quality.
- Performance benchmarks: open rate, reply rate, positive reply rate, meeting booked rate.

## Done Criteria

The initial research phase is complete when it includes:

- 20+ qualified sources documented.
- 10+ actionable insights ready for testing.
- 3-5 outreach message templates derived from findings.
